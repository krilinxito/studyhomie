# StudyHomie

An AI study assistant that runs on your computer: ask for what you want to understand and it writes a guide with interactive visuals, maps the iceberg of what the topic takes for granted, builds roadmaps for whole subjects and makes you practice until you can explain it. Your notes stay on your disk, in Markdown, compatible with Obsidian.

```sh
npm install -g studyhomie
mkdir estudios && cd estudios
studyhomie init
studyhomie
```

This package downloads the StudyHomie binary for your system from the [GitHub release](https://github.com/krilinxito/studyhomie/releases) of the same version and checks its SHA-256. Update with `npm install -g studyhomie@latest`.

More: <https://studyhomie.maxi42.space>
